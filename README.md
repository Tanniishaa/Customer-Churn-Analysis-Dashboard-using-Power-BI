# Customer-Churn-Analysis-Dashboard-using-Power-BI
This project focuses on analyzing customer churn using an interactive Power BI dashboard. The goal is to identify key factors influencing customer attrition and provide actionable insights to improve customer retention strategies.

# Objectives
Analyze customer behavior and churn patterns

Identify high-risk customer segments

Understand key drivers behind churn

Provide data-driven recommendations for retention

# Key Insights 
Customers with month-to-month contracts have the highest churn rate

High monthly charges are strongly correlated with increased churn

Customers using electronic check payment method tend to churn more

Lack of value-added services (like tech support, online security) increases churn probability

Long-term contract customers (1-year / 2-year) show significantly higher retention\

# Impact
This dashboard helps businesses:

Reduce customer churn

Improve customer lifetime value (CLV)

Make proactive retention decisions

Identify revenue leakage
